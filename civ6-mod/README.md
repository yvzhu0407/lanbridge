# LANBridge 文明 6 局域网实验版

这是一个探索原型。Mod 为游戏原生「局域网游戏」入口增加 LANBridge 提示；它不会启动后台、连接网络、显示实时状态，也不会修改文明 6 的房间机制。连接网络仍需运行 LANBridge 客户端和配套命令行工具。

## 安装 Mod

将整个 `civ6-mod` 目录复制到文明 6 用户数据目录的 `Mods` 中，启动游戏并在「附加内容」启用 LANBridge。入口位于「多人游戏 → 局域网游戏 · LANBridge」。不同发行版的用户数据目录可能不同；如果原生 LAN 文字未变化，请确认 Mod 已启用并检查游戏日志。

## 实验网络

1. 管理员在 LANBridge 使用的 ZeroTier 控制器上准备一个开启广播、具有 IP 分配池的共享网络。所有参与者需要接入同一个网络；私有网络需由管理员逐个授权节点。现有 LANBridge 服务端不会自动创建或授权此共享网络。
2. 玩家启动本项目的 LANBridge 客户端，等待本机后台启动。实验前确保旧客户端已退出账号且不在旧房间：已有登录会话的房间轮询可能与共享网络控制冲突。退出账号会执行现有的离房和网络清理。
3. 在项目根目录构建：`go build -o lanbridge-civ6 ./cmd/lanbridge-civ6`。Windows 可使用 `go build -o lanbridge-civ6.exe ./cmd/lanbridge-civ6`。
4. 执行 `lanbridge-civ6 connect <16位网络ID>`，再执行 `lanbridge-civ6 status` 查看目标网络是否 `ready: true`。该命令调用当前客户端既有接口，会离开此 LANBridge 实例中已有的其他网络。连接成功只表示加入命令已完成，不代表房主可达或游戏房间可被发现。
5. 保持 LANBridge 客户端运行，在游戏的局域网大厅创建或加入游戏。关闭客户端会执行其现有网络清理流程。

连接时的权限提示、驱动和 planet 配置沿用现有客户端。固定共享网络必须属于该客户端使用的 ZeroTier 控制器/planet 环境；不能假定任意公开网络 ID 均可用。

## 尚未验证

- 游戏内加载、不同系统的 Mod 启用方式和多人大厅行为。
- 跨外网的房间广播发现、多个同时存在的游戏房间及实际游戏连接。
- Mod 与本地后台通信、游戏内实时网络状态及游戏房主识别。现阶段没有游戏内一键连接或成员延迟检测。
