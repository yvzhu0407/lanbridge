# 客户端使用说明

## 组成

从 [Releases](https://github.com/yvzhu0407/lanbridge/releases) 下载对应文件
（`SHA256SUMS.txt` 可用于校验下载完整性）：

| 文件 | 说明 |
|---|---|
| `LANBridge-<版本>-macOS-universal.dmg` | **macOS 安装包**，Apple Silicon 与 Intel 通用，自带 ZeroTier |
| `LANBridge-<版本>-windows-amd64-setup.exe` | **Windows 安装包**，自带 ZeroTier 与 TAP 驱动 |
| `lanbridge-server-<版本>-linux-amd64` / `-arm64` | 服务端二进制，该文件属于服务端 |

默认服务器地址由编译时的内置值决定；要连自己的服务器，
见 [DEPLOY.md](DEPLOY.md#第六步客户端指向你的服务器)。

## 安装

**macOS**：打开 `.dmg`，把 `LANBridge` 拖进 `Applications` 文件夹。

**Windows**：运行 `setup.exe`，默认装到 `C:\Program Files\LANBridge`，
会创建开始菜单和桌面快捷方式。安装包默认勾选「开机自启」——客户端需要常驻才能维持虚拟网卡，
不需要的话在安装时取消勾选。卸载走「控制面板 → 程序和功能」，或开始菜单里的卸载项。

## 第一次启动

1. macOS 从「应用程序」启动 `LANBridge`;Windows 双击桌面快捷方式。
2. **未签名提示**（本项目没有购买代码签名证书，产物是 ad-hoc 签名的）：
   - macOS 首次打开会被 Gatekeeper 拦下，**右键点 App →「打开」→ 再确认一次**即可；
     若仍被拦，在终端执行 `xattr -dr com.apple.quarantine /Applications/LANBridge.app`。
   - Windows 安装包和程序首次运行会出现 SmartScreen「Windows 已保护你的电脑」，
     点「更多信息」→「仍要运行」。
3. Windows 会请求 UAC 管理员授权(安装 TAP 虚拟网卡驱动);macOS 启动 ZeroTier 时
   会要一次管理员密码。取消授权会导致虚拟网卡无法创建。
4. 首次运行会自动解压内嵌的 ZeroTier 并启动独立实例(端口 9995),
   不影响你机器上已安装的 ZeroTier。

## 使用

1. 注册账号(用户名 + 密码 ≥ 4 位)。
2. **创建房间**:填房间名,选择游戏,点「创建并进入」。
3. **加入房间**:在大厅列表里点别人的房间 →「加入」。
4. 进房后等待几秒,卡片上会出现你的虚拟 IP(`10.147.x.y`)和房间成员列表。
5. 复制 IP 发给朋友;游戏内选【多人模式】→【局域网 / LAN】,就能在列表里看到主机。
6. 房间里有聊天面板,可以给在线成员发文字,会显示每个成员的送达状态。

## 常见问题

**进房后一直显示「正在下发…」**
- 检查网络能否访问服务器(默认 `172.252.125.40:8800`);
- 看日志 `~/.lanbridge/client.log`,搜索「诊断」段落。

**游戏里看不到房间**
- 双方都必须在同一房间,并且都显示了虚拟 IP;
- Windows 上确认防火墙允许虚拟网段入站(程序会自动加规则,
  但火绒等安全软件可能拦截,需要手动放行);
- 文明6 等游戏要在**同一房间内**进入局域网模式,不能一个在互联网模式。

**能 ping 通但游戏连不上**
- 确认游戏显示的是虚拟 IP,而不是物理网卡的 IP;
- Windows 上程序会把虚拟网卡跃点降到 1,退出时恢复;
  若之前异常退出,重启客户端会自动恢复。

**聊天发不出去**
- 8890 端口被占用时,日志会写「聊天服务启动失败」;
- 「已确认 0/N」表示对方没收到:确认对方客户端在线、且在你的成员列表里有 IP。

**Windows 提示驱动安装失败**
- 以管理员身份重新启动客户端;仍失败时看 `zt-node.log`;
- 部分安全软件会拦截未签名程序内嵌的驱动,需要加白名单。

## 数据与卸载

- 数据目录:`~/.lanbridge/`(macOS)、双击运行时同一账号下的 `~/.lanbridge/`;
  Windows 的内嵌 ZeroTier 在 `%ProgramData%\lanbridge\`。
- **macOS 卸载**:把 `LANBridge` 从「应用程序」拖进废纸篓。
- **Windows 卸载**:「控制面板 → 程序和功能 → 桥联 LANBridge」,或开始菜单里的卸载项。
  卸载器会结束残留进程、删掉程序目录、快捷方式和开机自启项。
- 卸载**不会**删除数据目录,重装时可直接复用;要彻底清理请手动删除上述目录。
- Windows 上内嵌的 TAP 驱动和防火墙规则也不会随卸载移除——
  它们可能被同机的其他 ZeroTier 实例共用,误删会破坏别人的网络。
  确认无人使用后,可在「设备管理器」/「防火墙高级设置」中手动清理。

## 已知限制

- Windows 需要系统已安装 WebView2 Runtime(Windows 11 默认自带)。
- 房间聊天只保证在线成员实时互通,不保存历史、不补发离线消息。
- 房间上限 254 个,单个房间最多 253 人。
